### 🔁 What is Redux Persist?

Imagine you have a React app where users log in. Normally, when the page **reloads** or the browser is **refreshed**, the app forgets everything stored in Redux — including whether the user is logged in. 😢

**Redux Persist solves this!** 🎉

It **saves your Redux store to the browser’s localStorage** (or sessionStorage), so even if the user refreshes the page, your app **remembers** the Redux state.

---

### 🧠 Think of it like this:

- Redux = your app's temporary memory (gets wiped on reload)
- Redux Persist = a notebook (it writes Redux state into localStorage)
- When the app reloads, Redux Persist reads from the notebook and restores the state.

---

### 💻 Example Use Case:

Let’s say a user logs in:

1. You save their info in Redux: `auth: { isLoggedIn: true, name: "Ashritha" }`
2. Redux Persist stores this in localStorage.
3. If the user **reloads the page**, Redux Persist pulls that saved state and **restores it automatically**.
4. So the app still knows the user is logged in — no need to log in again!

---

### ✅ Summary

> **Without Redux Persist** → Redux state is lost on refresh.  
> **With Redux Persist** → Redux state is saved & restored, so refresh doesn't reset the app.
